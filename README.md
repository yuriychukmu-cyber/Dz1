# Домашнее задание 1. C++ / Qt Widgets

Учебный проект на **C++17 + Qt Widgets + CMake**.

## Что реализовано
- 3 фигуры: равнобедренный треугольник, параллелограмм, бант (как на образце).
- Рисование **только контура** фигур (без заливки).
- Одновременное вертикальное движение всех фигур с разной скоростью.
- Отражение от верхней и нижней границ области рисования.
- Кнопки: `Старт`, `Стоп`, `Сброс`.
- Статус: `Анимация запущена` / `Анимация остановлена`.

## Полиморфизм
- Базовый класс: `GraphicObject`.
- Наследники: `IsoscelesTriangle`, `Parallelogram`, `BowShape`.
- Хранение в `std::vector<std::unique_ptr<GraphicObject>>`.
- В цикле таймера вызываются методы базового интерфейса.

## Сборка в Qt Creator
1. Открыть `CMakeLists.txt`.
2. Выбрать Kit с Qt5/Qt6.
3. Configure → Build → Run.

## Проверка
1. Нажать `Старт` — все фигуры движутся вертикально.
2. Дождаться границ — фигуры отражаются.
3. Нажать `Стоп` — движение останавливается.
4. Нажать `Сброс` — фигуры возвращаются на стартовые позиции.
