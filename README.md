# Домашнее задание 1. С++ / Qt Widgets

## 1. Название работы
**Анимация трёх графических объектов в Qt Widgets с использованием полиморфизма.**

## 2. Цель работы
Изучить базовые средства построения графического интерфейса в Qt и реализовать движение нескольких фигур через единый полиморфный интерфейс.

## 3. Краткое описание интерфейса
Приложение содержит:
- область рисования (`CanvasWidget`),
- кнопки `Старт`, `Стоп`, `Сброс`, `Выход`,
- строку состояния анимации (`Анимация запущена` / `Анимация остановлена`),
- краткую инструкцию в верхней части окна.

## 4. Описание реализованного полиморфизма
В проекте есть абстрактный базовый класс `GraphicObject`, который задаёт единый контракт:
- `draw(QPainter&) const` — рисование фигуры;
- `boundingRect() const` — текущие границы фигуры;
- `moveWithin(int topBoundary, int bottomBoundary)` — вертикальное движение и отражение от границ;
- `reset()` — возврат к исходному состоянию.

Классы `IsoscelesTriangle`, `Parallelogram`, `BowShape` наследуются от `GraphicObject` и переопределяют рисование/геометрию.

В `CanvasWidget` все объекты хранятся в контейнере:
`std::vector<std::unique_ptr<GraphicObject>>`.

По таймеру вызывается общий полиморфный интерфейс для всех фигур: движение и рисование идут через базовый тип.

## 5. Какие классы есть в проекте
- `MainWindow` — главное окно и элементы управления.
- `CanvasWidget` — область рисования и анимационный цикл.
- `GraphicObject` — базовый абстрактный класс.
- `IsoscelesTriangle` — равнобедренный треугольник.
- `Parallelogram` — параллелограмм.
- `BowShape` — бант (составная фигура).

## 6. Как работает движение фигур
- Все три фигуры двигаются одновременно только по вертикали.
- У каждой фигуры своя скорость.
- При достижении верхней/нижней границы видимой области направление меняется.
- Коррекция координат выполняется сразу при касании границы, поэтому фигуры не уходят за пределы области рисования.

## 7. Как собрать проект в Qt Creator
1. Откройте Qt Creator.
2. `File -> Open File or Project...`.
3. Выберите `CMakeLists.txt` этого проекта.
4. Выберите комплект (Kit) с Qt 5 или Qt 6 и компилятором C++17.
5. Нажмите **Configure Project**.
6. Выполните **Build** и **Run**.

## 8. Как тестировать программу
1. После запуска проверьте, что видны три фигуры: треугольник, параллелограмм, бант.
2. Нажмите `Старт` — фигуры должны начать двигаться одновременно.
3. Убедитесь, что скорости различаются.
4. Дождитесь касания верхней и нижней границ — фигуры должны отражаться и двигаться обратно.
5. Нажмите `Стоп` — движение прекращается.
6. Нажмите `Сброс` — фигуры возвращаются в исходные позиции.
7. Нажмите `Выход` — приложение закрывается.

## 9. Краткое описание для будущего отчёта
### Диаграмма классов
- Базовый класс `GraphicObject`.
- Три наследника: `IsoscelesTriangle`, `Parallelogram`, `BowShape`.
- `CanvasWidget` агрегирует коллекцию указателей на `GraphicObject`.
- `MainWindow` содержит `CanvasWidget` и элементы управления.

### Граф состояний интерфейса
- **Состояние 1:** анимация остановлена.
- **Переход `Старт`:** запуск таймера, переход в состояние «анимация запущена».
- **Переход `Стоп`:** остановка таймера, возврат в состояние «анимация остановлена».
- **Переход `Сброс`:** восстановление начальных параметров фигур (без принудительного изменения состояния запуска).

### Объектная декомпозиция
- GUI-слой: `MainWindow`, `CanvasWidget`.
- Модель графических объектов: `GraphicObject` и наследники.
- Механизм анимации: `QTimer` + периодическое обновление координат + `paintEvent`.
